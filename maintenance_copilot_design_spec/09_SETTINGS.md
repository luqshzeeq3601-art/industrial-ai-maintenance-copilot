# Settings Page

## Purpose
Manage user profile and application preferences without overwhelming the operator.

## Layout
- Left settings navigation
- Main form content

## Settings Navigation
- Profile
- Notifications
- Appearance
- System

Optional admin-only:
- Users & Roles
- Integrations
- Plant & Assets
- Security

## Profile
- Avatar
- Name
- Role
- Full name
- Email
- Department
- Plant
- Language / timezone if needed
- Save changes

## Rules
- Group related fields
- Avoid showing technical infrastructure unless user has admin role
- Keep destructive actions separated
- Use standard form labels and helper text only when needed
- Save button remains obvious but not oversized
