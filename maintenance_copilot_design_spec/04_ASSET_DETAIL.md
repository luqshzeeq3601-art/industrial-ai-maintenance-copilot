# Asset Detail Page

## Purpose
Show the selected machine’s identity, condition, maintenance state, telemetry summary, and recent operational activity.

## Header
- Back to Assets
- Machine image
- Machine name
- Fault/Running status
- Asset ID
- Location
- Plant
- Asset type
- Compact actions:
  - View 3D
  - Create Work Order
  - Open SOP
  - More

## KPI Row
- Operating hours
- Next service
- Condition

Do not exceed 3 primary KPI blocks.

## Critical Alarm
For fault state:
- warning icon
- fault code
- short fault title
- one-line description
- primary action: View Diagnostics

## Tabs
- Overview
- Diagnostics
- SOPs
- Work Orders
- History
- Parts

## Overview
Left:
- Key metrics / telemetry
- Recent activity

Right:
- Asset information
- Current status

Keep descriptions short and use icons where labels are obvious.
