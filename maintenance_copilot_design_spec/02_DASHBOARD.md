# Dashboard Page

## Purpose
Provide a fast operational overview of fleet health, downtime, work volume, and current asset state.

## Top Summary
Compact KPI cards:
- Plant availability
- Operating hours
- Cumulative downtime
- Active work orders

Each card:
- one icon
- one primary value
- one short context line
- optional compact trend graphic

Avoid oversized equal cards and unnecessary paragraphs.

## Andon Board
Show selected/high-priority assets as compact operational cards.

Each card:
- machine thumbnail
- machine name
- asset ID
- location
- operating hours
- status icon + label

Use tinted background only for Fault or Maintenance.

## Lower Analytics
Use 3 compact sections:
- Fleet health
- Repairs by fault type
- Recent activity or Operating hours & wear

Avoid decorative charts. Prefer operationally useful comparisons.

## Typography
- Page title: 30px
- KPI value: Geist Mono 28–32px
- Card title: 15–16px
- Technical values: Geist Mono 13–16px

## Interaction
- Time range filter
- Refresh
- View all assets
- Asset cards open Asset Detail
