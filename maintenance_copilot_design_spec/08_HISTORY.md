# History Page

## Purpose
Provide an auditable timeline of alarms, diagnostics, work orders, maintenance events, SOP views, and configuration changes.

## Filters
- Time range
- Type
- Asset
- User
- Reset

## Table
Columns:
- Time
- Type
- Asset
- Description
- User
- Action

## Event Icons
Use distinct icons for:
- Alarm
- Diagnostic
- Work order
- Maintenance
- Asset status
- Downtime
- SOP
- Settings

Avoid repeating colored pills for every event.

## Rules
- Timestamp and asset ID use Geist Mono
- Description remains short
- `View` or overflow action opens event detail
- pagination at bottom
