# Login / Welcome Page

## Purpose
Authenticate operators and provide fast role-based access without exposing the application dashboard behind the form.

## Layout
- Full-page standalone screen
- Two-column desktop composition
- Left: industrial plant visual + concise product value
- Right: sign-in card

## Left Panel
- Maintenance Copilot logo
- Heading: `Smarter Maintenance for Reliable Operations`
- One short supporting sentence
- 3–4 icon-led benefits:
  - Real-time asset monitoring
  - AI-assisted diagnostics
  - Work order management
  - Safer operations

Avoid long marketing copy.

## Sign-In Card
- Product mark
- `Sign in`
- Username
- Password
- Primary `Sign in` button
- Divider
- Two role shortcuts:
  - Supervisor
  - Technician

Use icon-led role cards with minimal copy.

## Typography
- Heading: Inter 36–44px / 700
- Form labels: Inter 13px / 600
- Input: Inter 14px
- Buttons: Inter 14px / 600

## UI Rules
- No dashboard visible behind login
- No modal treatment
- No glassmorphism
- Minimal shadow
- 44px minimum controls
